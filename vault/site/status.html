What this page cannot tell you

It is served from the same machine as the hub, so it is not an independent monitor and should not be your only source of truth.

What it does distinguish is worth something: the page itself is a static file, while the hub is a separate process behind it. If this page loads and the check below fails, the hub has stopped answering while the machine is otherwise up. If this page does not load at all, assume everything is down — a status page hosted on the thing it reports on cannot report its own absence.

Genuine independence needs probing from somewhere else entirely. Until that exists, this page is honest about being a convenience rather than a guarantee.
