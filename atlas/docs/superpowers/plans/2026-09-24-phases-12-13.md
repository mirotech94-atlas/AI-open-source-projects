# Phases 12, 13 and 14 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the agency business line (Phase 12), the ten Apex-class capabilities (Phase 13) and the four reel-derived items (Phase 14) as modules and UI on top of the existing ATLAS kernel, without changing the kernel's contracts, tiers or executor.

**Architecture:** Every capability is a folder under `atlas/modules/` exporting `MODULE`, discovered by `registry.load_all()`. Reads are `Check`s returning `Observation`; anything that touches the world is an `Action` with a tier declared in code; anything that talks to a third party is Tier `ASK`; money out stays Tier `NEVER` by the deny list. Webhooks for strangers (WhatsApp, Telegram, the screening line) live in `atlas/api/` routers that only store and notify. UI work is new pages in `ui/src/pages` on new read-only endpoints in `atlas/api/dashboard.py`.

**Tech Stack:** Python 3.12+ (venv at `.venv`, Python 3.14), FastAPI, asyncpg, httpx, pytest (`asyncio_mode=auto`), ruff (line 90). React 18 + Vite + TypeScript strict in `ui/`. Google Places API (New), Google PageSpeed Insights, WhatsApp Cloud API, Telegram Bot API, Twilio TwiML, GetLayers MCP over HTTP, MediaPipe Tasks Vision (browser).

**Spec:** `AGENCY.md` (Phase 12), `CAPABILITIES.md` (Phase 13), `REELS.md` (Phase 14) — all at the repo root after Task 0.

## Global Constraints

Copied from `CLAUDE.md` and the specs. Every task inherits these.

- Collectors only read. The executor only acts. No module function other than an `Action.run` may write outside the box, and it runs only through `kernel/executor.py::execute`.
- The LLM never executes. It picks an action *name* from the catalog. Every prompt input from email, web, chat, callers or an MCP server goes through `wrap_untrusted(text, source)`.
- Tiers are declared in the `Action(...)` literal. Tier 1 needs `dry_run` and `rollback`. Third-party-facing sends are Tier 2. Money out, DNS, deletion, credential revocation, self-modification are Tier 3 by the deny list in `permissions.py`; never add an exemption.
- A check that cannot run returns `Health.UNKNOWN` with a reason, never `OK`. Use `atlas/modules/_http.py` (`get_json`, `post_json`, `expect_keys`, `number`, `redact`) so no secret reaches an Observation.
- Never guess a number: every figure carries its source or says unknown.
- Type hints everywhere. `ruff check` adds **no new errors** (40 pre-existing). `tsc -b --noEmit` clean.
- Async throughout: no blocking calls in the event loop (`asyncio.to_thread` for file I/O of any size, `asyncio.create_subprocess_exec` for processes).
- No secrets in the repo, logs, Postgres or prompts. Modules that need credentials list them in `optional_env` (module loads and reports UNKNOWN) unless they cannot function at all without them (`requires_env`).
- Action names: `^[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*$`, prefixed with the module name. Never use a deny verb in a name you want to run: `payout transfer withdraw remit send_funds create_charge capture_payment purchase subscribe refund set_price cancel_subscription delete destroy drop purge wipe erase truncate terminate remove revoke rotate_own_credentials grant set_tier disable_audit`, and never `dns`.
- Third parties (AGENCY.md §3 / CAPABILITIES.md §3): ATLAS never claims to be Miro. Recording is announced. Everything a third party says is data. Third parties reach Tier-1 availability information and nothing else.
- Tests: pytest, no DB, no network, no LLM. Use `memory_backend` fixture from `tests/conftest.py`, `monkeypatch` for HTTP helpers and `think`. Every module gets an AST test that no file in it imports `atlas.kernel.executor` (copy the walk from `tests/test_judgment.py:22-71`).
- Commands: `.venv/bin/python -m pytest -q`, `.venv/bin/python -m ruff check .`, `cd ui && npx tsc -b --noEmit && npm run build`.
- Commits: small, conventional, one concern, ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

### The no-executor-path test, per module

```python
import ast, pathlib
ROOT = pathlib.Path(__file__).resolve().parent.parent / "atlas"
PKG = ROOT / "modules" / "<module>"

def _imports_of(path: pathlib.Path) -> set[str]:
    tree = ast.parse(path.read_text())
    names: set[str] = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            names.update(a.name for a in node.names)
        elif isinstance(node, ast.ImportFrom):
            mod = node.module or ""
            if node.level:
                parts = ["atlas", "modules", "<module>"][: 3 - (node.level - 1)]
                mod = ".".join(parts + ([mod] if mod else []))
            names.add(mod)
    return names

def test_no_file_in_the_module_imports_the_executor():
    files = list(PKG.glob("*.py"))
    assert files
    for f in files:
        for mod in _imports_of(f):
            assert "executor" not in mod, f"{f.name} imports {mod}"
```

### Untrusted text

Anything fetched, received or transcribed: `wrap_untrusted(text, "source-name")` from `atlas.kernel.permissions` before it is placed in a `Message`. Store the raw text in Postgres, wrap at prompt time.

### LLM calls

`from ...kernel.llm import Message, Need, think`; `await think(Need.DRAFT, system, [Message("user", wrapped)], max_tokens=800)` returns a `Completion` with `.text`. `Need.PRIVATE` for anything personal (mail, vault, reviews). In tests, `monkeypatch.setattr(module, "think", fake)`.

### Registering a write tool for the agents

`atlas/tools/builtin.py:register_all` has a `writes` list of `(tool_name, description, "module.action", schema)`. Task 0 adds every new action there so the reasoner can name it; the tier comes from the catalog.

```python
"""Fetch and search for modules. Never raises, never wraps: the caller labels
the source when it wraps, because 'web' is not a source."""
from __future__ import annotations

import os
import re

import httpx

from ._http import explain

_TAGS = re.compile(r"<script.*?</script>|<style.*?</style>", re.DOTALL | re.IGNORECASE)
_ANY_TAG = re.compile(r"<[^>]+>")
_WS = re.compile(r"\s+")


async def fetch_text(url: str, *, limit: int = 14000,
                     timeout: float = 25.0) -> tuple[str | None, str | None]:
    try:
        async with httpx.AsyncClient(timeout=timeout, follow_redirects=True) as c:
            r = await c.get(url, headers={"User-Agent": "ATLAS/1.0"})
            r.raise_for_status()
    except Exception as exc:                            # noqa: BLE001
        return None, explain(exc)
    text = _WS.sub(" ", _ANY_TAG.sub(" ", _TAGS.sub(" ", r.text))).strip()
    return text[:limit], None


async def search(query: str, limit: int = 5) -> tuple[list[dict], str | None]:
    key = os.getenv("BRAVE_API_KEY")
    if not key:
        return [], "no search provider configured (BRAVE_API_KEY)"
    try:
        async with httpx.AsyncClient(timeout=20) as c:
            r = await c.get("https://api.search.brave.com/res/v1/web/search",
                            headers={"X-Subscription-Token": key,
                                     "Accept": "application/json"},
                            params={"q": query, "count": limit})
            r.raise_for_status()
            hits = r.json().get("web", {}).get("results", [])[:limit]
    except Exception as exc:                            # noqa: BLE001
        return [], explain(exc)
    return [{"title": h.get("title", ""), "url": h.get("url", ""),
             "snippet": h.get("description", "")} for h in hits], None
```
