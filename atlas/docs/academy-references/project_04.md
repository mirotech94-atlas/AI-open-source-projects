## Beginner mistakes they address

- Writing one long prompt every time instead of packaging it once (Nassr, Stratvert).
- Giving no examples, so the skill guesses the format (Nassr).
- Relying on automatic pick-up when calling the skill by name is more reliable (Stratvert 2026).
- Not testing against a real input before relying on it (Stratvert 2026).

## What they do badly, and what we do better

- Skills shown in the chat apps only; ours is a project skill in a real folder, next to the code it governs.
- The skill is written by a helper skill and not read; we read the SKILL.md line by line and keep it short and checkable.
- No rule that must always hold; we show one hard rule and test that it holds.
- A plan requirement mentioned in passing without a date; we state no plan or price we have not read that day.
