## How they open

All three state what the viewer will have built by the end before anything else, but none shows it running first. The official n8n episode greets, names the series, then lists the skills covered (chat trigger, model, memory, prompts). Metics Media promises an agent built step by step, then spends its first minute on account sign-up and an affiliate link. Nate Herk promises a retrieval agent built with no code and says it is simpler than people expect, then goes to a definition.

## The order they explain things

- n8n: what a language model does versus what an agent adds (goals, tool calls, several steps), where n8n fits (mixing fixed steps with AI steps), then the build: chat trigger, AI Agent node, chat model credential, a first run, agent settings, the system message, memory, activating the workflow and the public chat, troubleshooting once live.
- Metics Media: sign-up, chat trigger, the AI Agent node and its slots (model, memory, tools), the model credential and API billing, simple memory, tools, then a schedule trigger, a daily briefing sent by Gmail, logging to Sheets, and templates.
- Nate Herk: what retrieval-augmented generation means, what a vector store is, the pipeline that loads a document, then the agent that queries it, credentials, a test, reading the agent's logs, memory last.

## Examples and analogies

- The language model called the agent's brain (Metics Media; also common elsewhere).
- An agent pictured as a model that can think in several steps and reach for a tool, against a model that only turns text into text (n8n).
- Looking a fact up on the web before answering, used to explain retrieval (Herk); fruit and animal words clustering in a vector space (Herk).
- A daily news briefing emailed each morning as the agent's real job (Metics Media).
- Checking an email address with a plain rule rather than an agent, as an example of not using AI everywhere (n8n).

## Beginner mistakes they address

- Thinking a chat subscription covers API use: the API is billed per use and needs its own key (Metics Media).
- Treating the API key as anything but a password (Metics Media).
- Expecting the agent to remember the conversation without a memory node (n8n, Metics Media).
- Putting everything in the user message instead of a system message (n8n).
- Using an agent for a step a fixed rule handles better (n8n).

## Pacing

Measured: all three run 20-24 minutes, far past our length. The official episode is calm and explains every setting it touches; Metics Media is fast and keeps adding features; Herk front-loads slides before any build. The n8n and Metics chapters name the feature being added, which is the searchable pattern.

## What they do badly, and what we do better

- None opens on the agent answering with its tool and memory; we open on that result.
- Twenty-plus minutes and many add-ons (email, sheets, templates, self-hosting) in one lesson; we build one agent with one tool and memory.
- Affiliate sign-up in the first minute (Metics Media); we have none.
- Prices and plan details said in passing; we state no price we have not read that day.
- No approval step before the agent acts; ours shows where a person approves.

## What we take (structure only)

1. One line on model versus agent, then straight into the editor.
2. Build in the order the node's slots appear: trigger, agent, model, first run.
3. Add memory, and show the forgetting first so the fix is visible.
4. Add one tool and show the agent choosing it in the logs.
5. Close on the system message and a safety habit, then the lab.
