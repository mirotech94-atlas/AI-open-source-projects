## How they open

All three cover the desktop app; none installs from the terminal, which
only Teacher's Tech mentions as the Linux route. Teacher's Tech opens on
three outcomes (sort files, draft content, an assistant that remembers),
names the maker and the free-then-paid plan, then spends a minute on what
the product is and what sets it apart from a chat window before touching
the download. TheAIGRID says in one sentence that this is an install guide
and is on the download page within seconds. Alex Hitt does the same and
narrates each click from the first line. None shows the agent doing
anything useful before the install starts.

## The order they explain things

- Teacher's Tech: what it is, download and the one-time guided build,
  connecting a free model through the maker's own portal with a matching
  pairing code, a first message, asking it what tools it has, a writing
  task, a web research task, hitting the free plan's limit with an image
  request, what the paid plan changes, choosing a cheap main model and
  why helper jobs follow it, safety switches, then three real jobs in one
  practice folder (sort, read invoices, save as a skill), a one-page site,
  a proper risks section, memory across sessions, the floating bar and
  voice, scheduled jobs and why they stop when the laptop sleeps.
- TheAIGRID: install time, whether it replaces an existing install, then a
  settings walk-through (remote backend, keys, model, appearance, memory,
  voice), profiles, skills and why they fail without the right provider,
  scheduled jobs, live subagents, messaging apps, the usage counter.
- Alex Hitt: download and drag to Applications, first launch, then a tour of
  every sidebar item and every settings page in order, ending in a spoken
  conversation with the agent about what voice mode costs.

## Examples and analogies

- A fictional small coffee roaster used for every demo, so tasks look like
  real work: a launch post, a grinder comparison, invoice totals, renamed
  product photos, an event page built from the planning notes in the folder
  (Teacher's Tech).
- An image request used twice, once to show the free plan's wall and once
  to show what paying adds (Teacher's Tech).
- Memory compared to correcting a new hire once (Teacher's Tech).
- A separate profile per job, such as an investing agent (TheAIGRID).
- A morning email briefing as the sample scheduled job (TheAIGRID).

## Beginner mistakes they address

- Expecting the chat to answer before any model provider is connected
  (TheAIGRID).
- Using the biggest model as the main one, so every helper task runs on it
  too and credits drain (Teacher's Tech).
- Leaving approvals on the automatic default in week one; Teacher's Tech
  switches to manual and turns on file checkpoints first.
- Pointing the agent at real files before watching it work on copies.
- Letting it near logged-in accounts and the browser on day one.
- Scheduling jobs that change things while nobody is watching.
- Expecting scheduled jobs to run with the laptop closed.
- Skills that error because the provider behind them is not connected
  (TheAIGRID).

## Pacing

Measured above: from about 181 to 245 words a minute. Teacher's Tech is the
calmest and the longest, and its first on-screen action by the heuristic is
late (just under six minutes) because the install and model hookup are
narrated as explanation; the two short videos start clicking within the
first quarter minute. Teacher's Tech and TheAIGRID both have many chapters
(17 and 16); TheAIGRID's are phrased as search questions rather than steps.
Alex Hitt reads settings names off the screen in long runs with little
explanation of any of them.

## What they do badly, and what we do better

- Two of the three are settings tours, not setups: nothing is done with the
  agent. We install, connect one model, and finish one task.
- Alex Hitt turns approvals off and several risky switches on, on camera,
  with no warning. We never show that, and we say why approvals stay on.
- Long lists of providers and keys read aloud. We pick one route and name
  that alternatives exist.
- TheAIGRID uses filler phrases heavily and repeats points. We script each
  sentence.
- Teacher's Tech's paid-plan comparison is useful but sits in the middle of
  the setup; we keep money to one short section and say the price was true
  on the day we recorded.
- Only one video gives a version or date for what is on screen. We show the
  version on screen at the start.

## What we take (structure only)

1. Say in the first seconds what the agent will do by the end of the episode,
   then install.
2. Install, connect one model provider, and send a first message to prove
   the wiring before any tour.
3. Set the safety switches (manual approval, file checkpoints, one practice
   folder) before the first real task.
4. Do one real task on a folder of copies and read every approval prompt
   aloud before accepting it.
5. Show one limit honestly (the thing it cannot do on this setup) and what
   changes it.
6. Close on what keeps running only while the machine is awake.
