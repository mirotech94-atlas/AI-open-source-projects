The error-and-recovery card: the actual error highlighted in `error`, then Cause → Fix → Verified in one card, so the learner gets a practical recovery instead of a cut that hides it.

**The editor supplies:** the real error text (copied, not paraphrased), the cause in one sentence, the fix naming the exact control path, and the verification value seen after the fix.

**Behaviour:** the error panel gets a 4px `error` border the moment the error appears (a cut, not a fade). The card's three rows are revealed with the narration, each with `title-rise`; the Verified row turns `success` only after the re-run succeeds on camera. No shake, flash or red wash.

| Do | Don't |
|---|---|
| Keep the error in the episode; it is the most useful 20 seconds | Edit the mistake out and leave a silent jump |
| Name the real cause | Blame "a glitch" |
| Verify again after the fix | Mark Verified before re-running |
