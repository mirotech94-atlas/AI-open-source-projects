The portrait template for a 20–40-second Short or TikTok: a `shorts-hook` headline in the first second, the active app panel recomposed for 1080×1920, and a `shorts-caption` plate, all inside the vertical safe area (`safe-9-16-x`, `safe-9-16-top`, `safe-9-16-bottom`).

**The editor supplies:** the hook (three to five words: the result, the surprising mistake or the useful question), a fresh crop of the panel from the source recording (never the 16:9 edit squeezed), the captions, and the longer lesson's title for the ending.

**Behaviour:** the hook is on screen at frame 0; no logo-only opening. One action is taught. The ending resolves the problem, then names the related longer lesson by title. Verify text placement on the uploaded phone preview; the amber zones are where player chrome sits.

| Do | Don't |
|---|---|
| Recompose the panel so `shorts-caption` is the smallest text | Shrink a desktop screenshot to fit |
| Keep essential instructions in narration and captions | Rely on motion to carry the meaning |
| Name the longer lesson | Promise a link or feature the account cannot show |
