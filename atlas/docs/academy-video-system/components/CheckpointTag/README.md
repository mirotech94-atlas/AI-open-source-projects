The checkpoint: a "You should now see…" tag beside the real output so the learner can verify progress, plus the pause variant for a practice task. Also the closing beat that names the skill learned.

**The editor supplies:** the real output (a screenshot or the actual JSON, never retyped from memory), one sentence saying what to look for (one `code` value or file name in it), and for the pause variant, the task in one sentence.

**Behaviour:** the tag rises in on `title-rise`, holds for `hold-tag` (2–4 s) or until the narrator has read it, then rises out. The `success` border means the narrator checked the value on camera. The pause card uses `blue-tint`/`blue`, stays on screen, and the answer comes in a separate shot.

| Do | Don't |
|---|---|
| Hold the output long enough to compare line by line | Flash the tag and cut |
| Name the exact value or file to look for | Write "it should work now" |
| Show the pause prompt, then actually pause the narration | Answer the practice task in the same breath |
