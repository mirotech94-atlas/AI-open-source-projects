The persistent labels: a lower-third that introduces a tool or speaker once, the chapter label top-left, and the caption plate. All three live in the corners, outside the task area the cursor works in.

**The editor supplies:** the tool or speaker name (`callout`) and one-line role (`support`); the chapter name; captions at phrase level with technical names spelled as the product spells them.

**Behaviour:** the lower-third enters with `title-rise`, holds `hold-tag` (about 3 s), exits with `title-rise`; it appears once per tool, not on every return. The chapter label is static for the whole chapter. The caption plate is `navy` at 80% opacity so app controls still show through; two lines maximum.

| Do | Don't |
|---|---|
| Introduce a tool the first time it is used | Re-run the lower-third every time the tool reappears |
| Keep captions bottom-centre and short | Let a caption cover a command, a field or a result |
| Spell node and product names exactly | Auto-caption without correcting technical names |
