# Tags, hashtags and getting seen

What YouTube itself says, what the top-performing videos in this niche actually use, and the exact sets to paste into Studio for each Atlas series.

## The facts first

- Tags play a minimal role in discovery (YouTube's own words). Title, thumbnail and description decide whether a video is shown and clicked; tags mainly catch misspellings and variants. Don't skip them, but don't expect them to rescue a weak title.
- Hashtags go in the description (or title). Up to three of them appear above the title; more than 60 and YouTube ignores all of them; unrelated hashtags count as misleading and can get the video pulled from search. No spaces inside a hashtag.
- Stuffing tags or hashtags into the description is a spam-policy violation. Keep the description a real description.

Source check: these come from YouTube Help's hashtag and tag pages (linked at the end).

## What the 100k+ view tutorials use

Two n8n beginner tutorials from different channels (Metics Media, 140k views; Youri van Hofwegen, 105k views) carry almost the same tag set — and neither uses a single hashtag. The pattern: every tag is a phrase a beginner would type, in several word orders, plus the channel name.

Their shared core, verbatim:

`n8n tutorial for beginners` · `n8n for beginners` · `n8n beginner tutorial` · `n8n ai agent tutorial` · `n8n tutorial ai agent` · `n8n tutorial ai` · `ai agents for beginners` · `ai agents beginner tutorial` · `ai agents course for beginners` · `how to build ai agents` · `how to build ai agents in n8n` · `master n8n ai agents for beginners` · `ai automation n8n` · `n8n ai automation` · `automation for beginners`

Three lessons from that:

1. Tags are search phrases, not single words. "n8n" alone does nothing; "n8n tutorial for beginners" does.
2. Reorder the same phrase three ways (`n8n ai agent tutorial`, `n8n tutorial ai agent`, `ai agent tutorial n8n`) — that is what the big channels do.
3. Add your channel name as a tag so your own videos cluster in Suggested.

## Title, thumbnail, description — where the views actually come from

- **Title formula that the top videos share:** `<tool> Tutorial for Beginners <year>: <outcome>` or `How to Build <specific thing> in <tool> (Step by Step)`. Front-load the tool name; put the year in when the UI has changed recently; promise the outcome the first three seconds will show.
- **Thumbnail:** one real screenshot, 2–5 words in `chapter` type, the same outcome as the title. No arrows-and-red-circles collage.
- **Description, first two lines:** the promised result and the prerequisite, because that is what shows before "more". Then chapters with timestamps (they appear in search as key moments), then links, then the hashtags. Chapters use the exact terms people search: "Add the Wait for approval node", not "Step 3".
- **Suggested, not search, is the bigger traffic source for tutorials.** End screens pointing to one specific next lesson, and a playlist per series with the same tag set, are how a viewer watches three Atlas videos instead of one.
- **Shorts feed the long form.** Every lesson gets one Short cut with the result or the mistake in the first second and the long lesson named at the end.
- **Measure in Studio → Analytics → Reach:** impressions click-through rate by video (aim upward from the channel's own median), and traffic source "YouTube search" terms, which tell you the real phrases to turn into tags and titles next time.

## Checklist before publish

- Title ≤ 60 characters, tool name first, matches the thumbnail and the first three seconds.
- Channel tags + series tags + 3–5 lesson tags, under 500 characters.
- 3–5 hashtags at the end of the description, strongest three first, all relevant.
- Chapters with searchable names; the kit link with one honest sentence.
- Added to the series playlist; end screen points to one existing next lesson.
