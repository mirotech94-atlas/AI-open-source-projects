# Episode structure

The beats every long-form lesson follows, with the component each one uses. Timings are starting points to test, not rules from the algorithm; YouTube's intro-retention measure reports who is still watching after 30 seconds, so the first three beats are the ones to experiment with.

## Opening (0–20 s)

| Time | Visual | Component | Narration purpose |
|---|---|---|---|
| 0–3 s | Finished draft beside the inquiry; "Ready for review" fades in | ResultTitle | State the promised outcome |
| 3–6 s | Trace inquiry → draft → review once; indicator stops at review | WorkflowTrace | "You check it before anything is sent" (only if the workflow enforces it) |
| 6–7 s | Wordmark, blue line draws beneath | BrandSting | A breath; narration keeps flowing |
| 7–12 s | Back to the real app; one-line scope and prerequisites | ResultTitle (support line) | Scope, accounts and costs stated accurately |
| 12–20 s | First action; exact control highlighted; result held | CursorRing | Teaching begins; definitions arrive when needed |

Skip the logo sequence and the welcome paragraph. Keep at most one short headline above the demonstration.

## Teaching loop (repeat)

Show the step → perform the action → inspect the result → explain the next decision. The camera moves only when the learner needs a different view.

| Moment | Treatment | Component |
|---|---|---|
| Orientation | Three- or four-step map; only the active step animates; position never changes | StepMap |
| Action | Crop into the panel; cursor ring pulses once at the click, then stops | CursorRing |
| Data movement | One labeled token moves between nodes; input and output values shown | WorkflowTrace |
| Checkpoint | "You should now see…" beside the real output; hold long enough to compare | CheckpointTag |
| Error and recovery | Highlight the actual error, name the cause, show the fix, verify again | ErrorRecovery |
| Concept | Brief diagram or glossary card, then back to the real app | StepMap (glossary variant) |
| Practice | One small task and a visible pause prompt; answer in a separate shot | CheckpointTag (pause variant) |

A 35-second passage, as a reference: 0–5 identify the field · 5–12 enter the example · 12–17 run · 17–25 hold and explain the real output · 25–30 animate where it goes · 30–35 name the next action.

## Ending (last 20 s)

| Time from end | Scene | Component |
|---|---|---|
| 20–15 s | Completed result; name the skill learned. No new lesson here | CheckpointTag |
| 15–5 s | Clean end-card layout with the right side empty for the native element; "Next, add the review step" | EndCard |
| 5–0 s | Same layout; finish the sentence; audio resolves; nothing fades away | EndCard |

Native end screens appear in the last 5–20 seconds of a video at least 25 seconds long; add the real video or playlist element in Studio and preview it. Mention the matching course or practice files only after the promised result is delivered and only when relevant; the exact link goes in the description.

## Shorts (20–40 s)

First second: the visible result, the surprising mistake or the useful question (ShortsFrame hook). Middle: one small action, the app panel recomposed for portrait. Captions phrase-level, correct technical names, inside the safe area. Ending: resolve the problem, then name the longer lesson. Never promise a link or feature the account does not have.
