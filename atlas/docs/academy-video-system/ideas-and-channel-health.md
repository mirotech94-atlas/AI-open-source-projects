## Twelve labs for the next quarter

Each is one promised result, one visible outcome, and one honest limit.

1. Inquiry to draft reply with human review (the opening example; the channel's anchor lesson).
2. Invoice follow-up agent: reads overdue invoices from a sheet, drafts three reminders, never sends without approval.
3. Lead qualifier: form submission → Claude scores and routes to a Slack channel, with the scoring rubric on screen.
4. Meeting notes to tasks: transcript in, tasks out in a task tool, with the error when the transcript is empty.
5. MCP from zero: build a tiny MCP server that returns inventory, connect it to Claude, ask it a question.
6. Claude Code builds an n8n workflow: show the skill, show what it got wrong, fix it by hand.
7. Receipt to bookkeeping: photo → structured JSON → sheet row, with a deliberately bad photo to show recovery.
8. Support FAQ agent with a knowledge file: show the answer when the file has the answer and when it doesn't.
9. Daily ops brief: cron trigger, three data sources, one Slack message; the lesson is scheduling and failure alerts.
10. Price watcher: scrape → compare → notify, with the rule for when not to scrape.
11. Weekly content repurposer: long lesson transcript → Short outline → caption file, reviewed before publish.
12. Cost control: measure what each workflow costs per run and cap it; the most-asked question in comments becomes a lesson.

Shorts come from the same labs: the first second is the result or the mistake; the long lesson is named at the end.

## Are my subscribers real?

Only YouTube Studio can answer this; vidIQ was not connected to the channel and had no credits, so these are the checks to run yourself.

1. Studio → Dashboard → Recent subscribers → See all: only public subscribers from the last 28 days appear; spam-flagged and suspended accounts are hidden. Open a sample of profiles: real viewers usually have a channel name, some activity or subscriptions; empty profiles created in bulk around the same date are the warning sign.
2. Analytics → Audience → "Subscribers" over time, and Analytics → Advanced mode → subscribers by **Subscription source** and by **Content**. Real subscribers arrive from specific videos and from search/suggested; bought or botted subscribers arrive in a spike from "Other/External" with no matching rise in views or watch time.
3. Compare subscribers gained with views and watch time per video. A video that gains 200 subscribers from 300 views is not real; a lesson that gains 20 from 2,000 is normal.
4. Comments: real subscribers ask about the step they are stuck on. Generic praise from new accounts in a burst is the pattern of a purchased batch.
5. YouTube removes spam subscribers and closed accounts on its own and shows a Studio alert when it does; a drop after such an alert means the count is now more accurate, not that the channel lost real people.

If a batch looks fake and you did not buy it, no action is needed beyond not engaging with it; YouTube's periodic purges remove them. Never buy subscribers, views or engagement; it breaks monetization eligibility and poisons the retention data this system depends on.

The outcomes that matter are the ones this system can move: first-30-second retention, average view duration, end-screen clicks and visits to agency.storefront.test/academy/ from video links. Subscriber count follows those.
