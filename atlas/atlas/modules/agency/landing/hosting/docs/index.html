Order a server

Four steps from the portal. The address shows on the server page when it is ready.

  1. 1

    Create

    Sign in to your hosting portal and choose Create server.

  2. 2

    Choose

    Pick a location, a size and an operating system.

  3. 3

    Add your key

    Select your SSH key, name the server and confirm.

  4. 4

    Connect

    Ready in a few minutes. Log in with your key.

Manage a server

Everything is on the server page.

  • Power

    Start, stop and restart.

  • Resize

    Pick a bigger size when you need more room. Take a backup first.

  • Backups

    Turn them on and restore from the same place.

  • Rebuild

    Reinstalling the operating system erases the disk. Back up first.

  • Delete

    Permanent. The data cannot be brought back.

SSH keys

A key is safer than a password. Make one, add the public half to the portal, keep the private half to yourself.

Turn off password logins once your key works. Keep the operating system updated.

# 1. make a key, press Enter at the prompts
ssh-keygen -t ed25519

# 2. copy the public key (the .pub file)
cat ~/.ssh/id_ed25519.pub

# 3. paste it under SSH keys in the portal, then connect
ssh root@your-server-address

Never share the private key, the file without .pub.
