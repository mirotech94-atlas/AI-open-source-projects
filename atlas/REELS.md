two images Miro sent — surfaced ideas worth checking against the eight

`CAPABILITIES.md` is Phase 13's: what each source showed, what ATLAS takes
from it, and what it rejects and why. Phases 17 (YouTube and marketing) and
19 (college) came from Miro's own messages, not from a source here.
A reel is somebody else's marketing, not a design document — nothing here is
added because a reel said so, only because it survives contact with

### What Phase 16 rejects

An agent that rewrites its own instructions (`DXLhXZQjYar`) — self-modification
is Tier 3 and "standing directives re-injected into system instructions" is
exactly the runtime override `CLAUDE.md` forbids; ATLAS keeps memory as data
the harness quotes, never as instructions it obeys. Smart-home relays and
per-agent model dropdowns in the UI — there are no write endpoints in the
dashboard beyond approvals, and model routing stays in `llm.py` by `Need`,
never a screen control. Anything sent to a third party without a proposal —
a brief to WhatsApp, a page shipped by voice with no gate, a camera feed read
as if it were the room. Every one of these is a rejection of the demo's
framing, not of the idea underneath it; what survives is listed in the takes
column above and built out as 16.1-16.8 in `BUILD_ORDER.md`.

### What Phase 18 rejects

*Consciousness.* `Ddlxuw8y70S` and `Db1HnwSub8d` both sell an agent with an
inner life, and what is built instead is an honest self-model: ATLAS knows and
says its own state — uptime, errors since deploy, what it did, what it
remembers, what it cannot measure, what it got wrong — and never claims to be
aware. The docstring says so in one sentence, so the next person to read the
file cannot mistake the feature for the claim. *Thresholds that retune
themselves* go with it: a detector that adjusts its own sensitivity is one
that can quietly stop detecting, and self-modification is Tier 3 besides.
*Content farms of fake people* (`DdHkoVIEYlt`, `DdrBSjkSys2`) are rejected
outright — no invented personas, no generated reviews, no unlabelled synthetic
media. The AI-stories account that survives posts stories labelled AI-made in
the caption, as Meta's disclosure rule requires, under a monthly render-credit
cap, with every post a Tier 2 proposal. *Autonomous containment*
(`DZteY4hJs29`) is rejected as a default: a firewall rule on a network he or a
client depends on is externally visible, so `guardian.contain` is Tier 2, it
exists only where a write-scope token was deliberately configured, and the
module keeps its read-scope token by design — the default install narrates and
proposes. *Maps* (`DX6PkOBIwBc`) are rejected because external tiles break the
mesh-only CSP; the document viewer underneath the idea is taken. And *silence
as an answer* is rejected again, in its newest disguise: a call that ends
without a no (`DdofeapRX3a`), a comment hidden while he sleeps
(`Da3bCbINuQf`), a course sold on ATLAS's own initiative (`DdozechopIC`).
Calling him anytime was never the question — that path is already CRITICAL
and already his. What Phase 18 adds around it is presence, brevity and a
ledger of its own mistakes.

### What Phase 20 rejects

*A tournament of a hundred stores* (`Dcy-HtENDlW`). A/B testing needs the
traffic, and ATLAS does not host the client's: what it can honestly do is
build a handful of deliberately different versions, rank them with a rubric
that cannot be flattered, and propose the best — five at most, one Style
between them, the rest attached and never deployed. A variant is measured
only when the client's own site gives ATLAS a number to read; until then the
experiment is `unmeasured`, not "winning". *Reviews on request*
(`DcaeL6yI9pj`) stay rejected as Task 36 ruled: a testimonial nobody wrote is
a fake, and the rubric's "no fabricated reviews" check vetoes a page that
carries one rather than marking it down. *Prices, sourcing and checkout* stay
the client's: no product is sourced from AliExpress, no price is inferred,
and a store page ends at "call or email to order" — the rubric's "no payment
form" check is the second veto. *Composio* is declined because it would be a
second pair of hands: it holds the credentials and performs the writes from
its own servers, and invariant 1 allows exactly one executor. *Screen
mirroring* (`DbrA5DosA48`) is declined because it needs a cable to the phone
and ATLAS lives on a server. What survives is small on purpose: one photo in,
a page out; five versions ranked; one more way to read a JavaScript page.
